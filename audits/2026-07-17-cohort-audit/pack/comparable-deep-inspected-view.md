# Comparable view — deep-inspected repositories only

**Why this supplement exists.** The person-level aggregates in
`final-output.md` and questions A/C/D average the rubric over each
subject's *entire* authored portfolio. That is a legitimate portfolio
view, but it conflates depth with size: a subject with 202 authored
repos (Hamel Husain) has 192 scored from mechanical signals only —
each low-confidence — which drags the whole-portfolio aggregate down
and floors the person verdict at INSUFFICIENT_EVIDENCE. A subject with
14 repos, all deep-inspected (Aakash Gupta), is scored almost entirely
on judgment signals. So the whole-portfolio ranking partly measures
*what fraction of the portfolio we inspected*, not who is deeper.

This table re-levels the field: the same rubric scores, averaged over
**only the deterministically-selected deep-inspected repositories**
(same count per subject — 10, plus flagship additions), which is the
apples-to-apples substance comparison. Popularity is excluded (it is a
distribution signal, reported only in question C). Still public
artifacts only; no private-competence or intent inference.
